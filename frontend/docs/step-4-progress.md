## 驗證結果

- `npm run build` 通過 TypeScript 與 Vite 建置。
- `npm test` 共 34 項通過：商業規則、預約返回資料、JPY 報價驗證、目錄映射、商品角色與腰帶限制、計價、未開放端點阻擋與網路錯誤。
- 前一階段後端 52 項 API 檢查通過；本次未改後端程式。
- 瀏覽器確認 3 個方案價格為 JPY 5,000／9,000／13,000，兩門市展開可讀到地址、交通與營業時間。
- 首頁選「東京・淺草／情侶／觀光／城市散策」，得到後端情侶方案 JPY 9,000，連結保留三個條件。
- 情侶詳情／試穿各有女生與男生 3 款和服；選擇商品與腰帶後，預約連結帶入實際 ID。東京排程可讀到每日 15 場。
- 七步流程可抵達「7 / 7 摘要確認」，正式報價維持停用；由 AI 預覽返回仍在同一摘要步驟。未提交個資、接受條款、建立預約、上傳照片或付款。
- `/try-on`、`/booking`、`/stores`、`/photography`、`/plans` 各檢查 390／768／1032px，共 15 組，文件寬度均未超出視窗；見 [響應式檢查](qa/step4-responsive.json)。暫時視窗尺寸已重設。
