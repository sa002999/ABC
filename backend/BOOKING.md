# 預約流程與即時庫存

## 本次範圍

已接上門市接待場次、逐件和服庫存、七步驟預約草稿、後端 TWD 報價，以及整筆 10 分鐘暫留。可從方案、收藏或 AI 試穿結果帶入搭配，草稿屬於登入會員並支援跨裝置恢復。

TapPay 付款、正式預約成立、確認信、QR 核銷、取消退款，以及門市出借／歸還／整備後台仍是後續工作。付款按鈕保持停用，不會用暫留成功冒充付款或正式預約。加購步驟目前明示配件與攝影預約尚未開放，不接受隱藏加購或虛構價格。

依使用者 2026-10-17 指示，人物品質判斷、AI 配件穿戴及 AI 場景合成保留為待辦。

初始化已完成。其他環境在 backend 目錄執行：

```powershell
.venv/Scripts/python.exe manage.py migrate
.venv/Scripts/python.exe manage.py seed-booking-demo
```

`seed-booking-demo` 建立往後 90 天測試場次，重跑只補缺少資料，不覆寫既有容量、庫存狀態或營運設定。正式資料到齊後須另行匯入／透過後續管理功能維護，不把測試件數視為真實庫存。

## 啟動與驗收

重啟 API 與原本的 `manage.py try-on-worker`。預約到期清理已接入同一個 worker，不需要第三個背景程序。也可手動執行：

```powershell
.venv/Scripts/python.exe manage.py cleanup-booking-holds
```

1. 登入後按「立即預約」，或從方案、收藏、試穿結果點進預約。
2. 選門市、日期與場次、1～3 位旅客，為每人選方案。
3. 暫不加購，填聯絡資料，進入確認步驟。
4. 報價前重新驗證全員名額、各商品與租借／整備期間，顯示目前 TWD 逐人明細與總額。報價不佔庫存。
5. 完成 Email 驗證的會員，可按「確認建立 10 分鐘暫留（測試）」。全員資源都可用才成功；缺一項整筆拒絕。
6. 重整後恢復同一筆暫留，期限不延長；可釋放後編輯。到期後重新報價、確認才建立新暫留。

推薦多人測試：京都同款和服可供 3 位旅客各配置一件；不足全員時應整筆拒絕。

## 一致性與資料保護

- 接待容量與和服實體庫存分開檢查；多人需求不會重複分配同一件商品。
- 庫存排他約束使用 PostgreSQL `btree_gist` 與時間區間，排除同件和服在租借＋整備重疊期間的 HELD／RESERVED 配置。取得暫留時以門市列鎖協調容量與全員庫存，全部在同一交易中完成。
- 草稿更新需版本；報價綁定會員、草稿版本與目前價格／租借規則，有效 5 分鐘。價格、場次版本或整備規則變動後，要求重新報價。
- 暫留必須有 UUID `Idempotency-Key`。同會員同鍵同內容回原暫留；同鍵不同內容回 409。重送與查詢不延長期限。瀏覽器只持久保存重送鍵與 quoteToken；聯絡資料不寫 localStorage／sessionStorage，僅存在會員草稿與頁面記憶體。
- 前端返回保留當前輸入，已儲存草稿可跨裝置讀取。恢復後仍須重新確認場次、庫存與價格。超過 3 人的舊草稿回傳修正提示，不自動截斷。
- 未驗證 Email 不可取得付款前暫留；身分與擁有權由後端決定，不能由 request 指定會員或總價。
- 暫留到期後，API 立即視為失效、查詢不再扣名額；新的暫留交易會先釋放該門市逾時配置，即使瀏覽器關閉也不會占住庫存。worker 同時定期清理狀態。付款待確認與正式保留不會按 10 分鐘期限誤釋放。
- 每位會員只有一份目前草稿，自建立起保存 7 天，更新及恢復不延長期限。開始預約時恢復同一份；POST 已有草稿時回 200，不覆蓋帶入資料，沒有草稿時回 201。以會員列鎖避免同時建立多份。舊版多份草稿優先恢復有有效暫留／付款待確認者，否則恢復最新更新者，舊資料保留原清理規則。
- 草稿過期或正式保留（RESERVED）後不再出現在草稿列表，下次開始預約才建立新草稿。正式付款與成立流程仍待實作，暫留到期不刪除尚未滿 7 天的草稿。
- 過期且沒有未結保留的草稿會由 worker 清除；未使用的逾期報價會清除，過期／釋放暫留的稽核資料保留 7 天後清除。未結付款資料不在此清除範圍。
- 公開場次只回總容量與剩餘名額，不含其他會員或其預約資訊。私人 API 與即時名額回應均 `Cache-Control: no-store`。

## API

| 方法 | 路徑 | 用途 |
|---|---|---|
| GET | `/api/stores/{storeId}/availability?from=YYYY-MM-DD&to=YYYY-MM-DD&partySize=1` | 日本日期範圍內的接待名額，每次最多 31 天；可帶 planId 檢查同款全員庫存 |
| POST／GET | `/api/booking-drafts` | 建立／列出本人草稿 |
| GET／PATCH | `/api/booking-drafts/{draftId}` | 恢復／以 version 更新本人草稿 |
| POST | `/api/pricing/quote` | draftId＋version，後端重新檢查與計價 |
| POST | `/api/availability/holds` | draftId＋quoteToken，需 Email 驗證與 Idempotency-Key |
| GET／DELETE | `/api/availability/holds/{holdId}` | 查詢原期限／釋放可取消暫留 |

DELETE 暫留是釋放未付款測試資源，不是取消正式預約；付款待確認與正式保留不得走此入口。
